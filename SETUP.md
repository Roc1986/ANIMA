# Cómo agregar las pantallas a ANIMA2

1. Copia la carpeta `src/` completa a `C:\Users\rayen\ANIMA2\`
2. En CMD, desde `C:\Users\rayen\ANIMA2\`:
   npm install @react-navigation/native @react-navigation/bottom-tabs @react-navigation/native-stack react-native-screens react-native-safe-area-context expo-linear-gradient
3. Reemplaza el contenido de `App.tsx` con:
   (ver App.tsx en este repo)
4. npx expo start --clear
